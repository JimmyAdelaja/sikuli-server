# Sikuli Server

### Build

```shell
mvn clean package
```

### Run Server

Download the [jar](https://github.com/JimmyAdelaja/sikuli-server/packages/3151111) and Run `sikuli-server-1.0-SNAPSHOT-jar-with-dependencies` as

```powershell
java --enable-native-access=ALL-UNNAMED -jar .\sikuli-server-1.0-SNAPSHOT-jar-with-dependencies.jar
```
